제품 방향

프로젝트의 계층형 WBS·간트에 담당자, 실제 상태, 버전 산출물과 검토를 연결합니다. 날짜 경과를 완료율로 쓰지 않으며 담당 배정은 비공개 열람권을 넓히지 않습니다.

범위는 제품 정의, 이유·계약은 구조와 결정, 위치는 프로젝트 지도를 확인해 주세요.

봉사활동 확장 V0–V4

사용자가 채택한 단계별 구현 계획입니다. 프로젝트 유형·참여자·활동팀과 팀 범위 팀장 관리 역할을 추가하고 기존 WBS를 재사용합니다. 제출 없이 완료도 필수 기능입니다. 확정 정책과 상세 계약은 설계 정본, 우선순위·작업 ID·현재 상태는 TODO에서 확인합니다.

모바일 우선 탐색과 팀 도구

모바일 주사용을 기준으로 기존 포털·업무/준비표 권한을 보존하면서 탐색과 도구 배치를 개선합니다. 현재 진행은 PRD-065/QLT-034가 소유합니다. 메뉴·팀 도구 소스와 지원 로컬 검사를 마쳤으며 실제 화면 인수/게시는 별도 확인합니다.

날짜·메뉴 중심의 간단한 식단

PRD-066/QLT-035의 구현 단계이며 소스/지원 로컬 검사를 마쳤고 실제 화면/게시 결과와 구분합니다. 현재 진행은 TODO를 따릅니다. 날짜·메뉴·진행상태만 필수로 두고 planned는 “준비 전” 기본값으로 날짜/메뉴부터 시작합니다. 끼니·예상인원·기준량·단위·메모·장보기는 선택이며 상세정보를 기본 접습니다. 선택 빈값 때문에 저장/공유를 차단하지 않습니다.

완료의 증거

코드 완료, 로컬/합성 검증, 운영 게시, 실제 사용자 인수는 서로 다른 결과입니다. 실행하지 못한 항목은 사유와 다음 행동을 남깁니다. 과거 검증 수치를 이번 실행 결과로 합산하지 않습니다.

명령·최소 게이트는 HARNESS_MAP, NAS/Sites 적용·복구는 운영 안내, 결정/게시/검증 이력은 완료 기록을 따릅니다. 사용자 교육은 HTML 설명서와 팀 업무 안내를 사용해 주세요.
