제품 방향

프로젝트의 계층형 WBS·간트에 담당자, 실제 상태, 버전 산출물과 검토를 연결합니다. 날짜 경과를 완료율로 쓰지 않으며 담당 배정은 비공개 열람권을 넓히지 않습니다.

범위는 제품 정의, 이유·계약은 구조와 결정, 위치는 프로젝트 지도를 확인해 주세요.

봉사활동 확장 V0–V4

사용자가 채택한 미구현 계획입니다. 프로젝트 유형·참여자·활동팀과 팀 범위 팀장 관리 역할을 추가하고 기존 WBS를 재사용합니다. 제출 없이 완료도 필수 기능입니다. 제안 정책과 상세 계약은 설계 정본, 우선순위·작업 ID·현재 상태는 TODO에서 확인합니다.

이 계획 갱신으로 기능 구현이나 운영 변경을 수행하지 않습니다. 봉사 대상자의 개인정보·아동 개별정보 수집은 초기 범위에서 제외합니다.

완료의 증거

코드 완료, 로컬/합성 검증, 운영 게시, 실제 사용자 인수는 서로 다른 결과입니다. 실행하지 못한 항목은 사유와 다음 행동을 남깁니다. 과거 검증 수치를 이번 실행 결과로 합산하지 않습니다.

명령·최소 게이트는 HARNESS_MAP, NAS/Sites 적용·복구는 운영 안내, 결정/게시/검증 이력은 완료 기록을 따릅니다. 사용자 교육은 HTML 설명서와 팀 업무 안내를 사용해 주세요.
