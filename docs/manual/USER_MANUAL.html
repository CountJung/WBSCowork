핵심 개념
WBSCowork의 기본 원칙
WBSCowork는 게시판이 아닙니다. 일반 협업툴이 아닙니다.
→ 태스크 기반 산출물 관리 시스템

세 가지 핵심 기능

  • WBS/간트 기반 업무 관리 — 주간 업무를 시각적으로 계획하고 추적
  • 태스크 단위 산출물 제출 — 각 태스크에 결과물을 체계적으로 등록
  • 팀원 간 피드백 & 협업 — 댓글을 통한 실시간 협업 및 피드백

역할 시스템
네 가지 사용자 역할
슈퍼관리자 (isSuperuser)
모든 권한: DB 관리, 환경설정, 사용자 관리, 모든 제출물 조회
관리자 (role: admin)
관리 권한: /admin, /admin/users 접근 가능, 모든 제출물 조회, 일반사용자/게스트 권한 부여
일반사용자 (role: member)
편집 권한: 태스크/제출물/댓글 CRUD, 공개 제출물 + 본인 비공개 제출물 조회
게스트 (role: guest)
읽기 권한: 공개 제출물만 조회 가능, 권한 승급 대기 중
제출물 공개 범위
visibility 설정으로 접근 제어

태스크 상세 화면

상세 화면의 구성

✨ 포커스 모드: 태스크를 열면 해당 태스크가 Gantt에서 강조되어 집중할 수 있습니다.

댓글 달기

  • 산출물 또는 태스크 하단의 댓글 섹션에 입력
  • 텍스트 기반 피드백으로 빠른 협업

  • 역할별 접근: 공개/비공개 댓글 구분
💬 권장: 긍정적이고 건설적인 피드백으로 팀 분위기를 좋게 유지하세요.

주요 기능 (슈퍼관리자 전용)

  • /admin/database: DB 테이블 생성 및 초기화
  • /admin/logs: 시스템 로그 조회 및 분석
  • /admin/settings: 환경변수 편집

사용자 관리 (관리자 + 슈퍼관리자)

/admin/users 에서 사용자 역할 변경 가능 (guest ↔ member)

데이터베이스 관리
슈퍼관리자의 DB 설정

초기 설정 (슈퍼관리자 전용)

/admin/database 에서:

  • DB 연결 확인: MariaDB 연결 상태 점검
  • 테이블 생성: 필요한 모든 테이블 자동 생성
  • 초기 데이터: 시스템 기본 프로젝트 생성

주요 테이블

users: 사용자 계정 정보
projects: 프로젝트

submissions: 산출물
comments: 댓글

시스템 상태 확인

로그 조회 (/admin/logs)

슈퍼관리자만 접근 가능

  • 구조화 로그: JSON 형식의 상세한 시스템 로그
  • 파일 로그: 서버 시작 이후의 모든 로그 기록
  • 실시간 추적: 최신 로그를 계속 업데이트

로그 저장 위치

/logs 디렉터리에 날짜별로 롤링 저장

모니터링 요점

  • 에러 발생 시 즉시 확인
  • 사용자 행동 추적 (감사)
  • 성능 병목 지점 파악
환경 설정
/admin/settings 관리

편집 가능한 설정 (슈퍼관리자 전용)

Google OAuth: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
인증: NEXTAUTH_URL, NEXTAUTH_SECRET
MariaDB: DB_HOST, DB_PORT, DB_NAME 등
파일 업로드: UPLOAD_MAX_FILE_SIZE_MB, UPLOAD_DIR
로깅: LOG_DIR, LOG_RETENTION_DAYS

주의사항

  • .env 파일은 시스템 시작 시 읽음
  • 민감한 정보 (비밀키)는 안전하게 관리
  • 변경 후 서버 재시작 필요 (일부 설정)

권한 변경 절차

  • 1/admin/users 로 이동
  • 2사용자 선택

역할 업그레이드 규칙

  • 관리자: guest/member 만 부여 가능 (슈퍼관리자만 admin 부여)
  • 슈퍼관리자: 환경변수에 지정된 이메일만 해당
  • SUPERUSER_EMAIL 예약: 해당 계정은 항상 슈퍼관리자

  • 댓글은 건설적이고 구체적으로 작성
  • 중요한 결정은 주석으로 기록

자주 묻는 질문
FAQ

Q. 산출물을 어떻게 삭제하나요?

산출물 작성자와 관리자만 삭제 가능합니다. 산출물 상세 화면에서 삭제 버튼을 클릭하세요.

Q. 공개 산출물을 비공개로 변경할 수 있나요?

네, 작성자는 산출물 공개 범위를 언제든지 변경할 수 있습니다.

Q. 태스크 순서를 변경할 수 있나요?

네, Gantt 차트에서 태스크를 드래그하여 시간 범위를 조정할 수 있습니다.

Q. 파일을 다시 다운로드할 수 있나요?

네, 모든 첨부 파일은 언제든지 다운로드할 수 있습니다.

  • 문서: 프로젝트 docs/ 폴더의 추가 문서 참조
