> **생성일:** 2026년 4월 26일  
> **테마:** Teal & Coral

## 📦 생성된 문서

WBSCowork 프로젝트를 위해 다음 4가지 형식의 사용설명서가 생성되었습니다:

### 1. **HTML 슬라이드 데크** (`USER_MANUAL.html`)
- **형식:** HTML (웹에서 직접 열 수 있음)
- **슬라이드:** 22개
- **용도:** 
  - 웹 브라우저에서 슬라이드 쇼로 직접 보기
  - PowerPoint로 변환하기 전 미리보기
  - 온라인 발표 자료로 사용
- **특징:**
  - Teal & Coral 테마 적용
  - 반응형 디자인
  - 모든 주요 기능을 포괄적으로 설명

### 2. **사용설명서 가이드** (`USER_MANUAL.md`)
- **형식:** Markdown
- **용도:** 
  - PowerPoint 변환 방법 상세 설명
  - 커스터마이징 가이드
  - 발표 팁 및 시간 관리
  - 참고 문서 링크
- **포함 내용:**
  - 22개 슬라이드 구성 상세
  - 색상 팔레트 정보
  - HTML-to-PPTX 변환 3가지 방법
  - 세션별 추천 슬라이드

### 3. **빠른 참조 카드** (`QUICK_REFERENCE.md`)
- **형식:** Markdown (인쇄 가능)
- **용도:** 
  - 한 페이지 정리된 요약
  - 발표 중 참고할 핸드아웃
  - 사용자 교육 자료
  - 팀원 온보딩 체크리스트
- **포함 내용:**
  - 핵심 개념 정리
  - 역할 및 권한 테이블
  - 주요 경로/URL 정리
  - 문제 해결 가이드
  - 환경변수 주요 설정

### 4. **PowerPoint 변환 스크립트** (`scripts/convert-manual-to-pptx.js`)
- **형식:** Node.js 스크립트
- **용도:** 
  - HTML → PowerPoint 자동 변환
  - 한 줄의 명령으로 PPTX 생성
- **특징:**
  - PptxGenJS 라이브러리 사용
  - Teal & Coral 색상 자동 적용
  - 15개 핵심 슬라이드 생성
  - 자동으로 `outputs/` 디렉터리에 저장

## 🚀 빠른 시작

### 옵션 A: HTML로 바로 보기 (가장 빠름)
```bash
# 웹 브라우저에서 열기
open docs/USER_MANUAL.html
# 또는
firefox docs/USER_MANUAL.html
```

### 옵션 B: PowerPoint로 변환 (권장)

#### 방법 1: 스크립트 사용
```bash
# 필수 설치 (처음 1회만)
npm install -g pptxgenjs

# 변환 실행
node scripts/convert-manual-to-pptx.js

# 결과: outputs/WBSCowork_Manual.pptx
```

#### 방법 2: 온라인 도구 사용
1. `docs/USER_MANUAL.html` 파일 열기
2. 온라인 HTML-to-PPTX 변환 도구에 업로드 (검색: "html to powerpoint")
3. 다운로드

#### 방법 3: 외부 저장소 사용
```bash
# tfriedel/claude-office-skills 저장소 활용
git clone https://github.com/tfriedel/claude-office-skills.git
cd claude-office-skills
npm install

# 변환 실행
node public/pptx/scripts/html2pptx.js /path/to/USER_MANUAL.html
```

### 옵션 C: 인쇄용 자료
```bash
# 빠른 참조 카드 출력
cat docs/QUICK_REFERENCE.md | print  # 또는 브라우저에서 인쇄
```

## 🎨 디자인 사양

### 색상 팔레트 (Teal & Coral)

| 색상 | Hex | 용도 |
|------|-----|------|
| 진한 티알 | #277884 | 헤더, 주요 텍스트 |
| 밝은 티알 | #5EA8A7 | 부제목, 강조 |
| 코랄 | #FE4447 | 액센트, 강조 버튼 |
| 화이트 | #FFFFFF | 배경 |
| 라이트 그레이 | #f5f5f5 | 배경 하이라이트 |

### 서체
- 주요 폰트: Arial, Helvetica (웹 안전 폰트)
- 헤더: 40-52pt, 굵음
- 본문: 16pt
- 캡션: 12-14pt

### 레이아웃
- 슬라이드 비율: 16:9 (와이드스크린)
- 여백: 0.5인치 (모든 변)
- 기본 그리드: 10x5.625인치

// 색상 변경
