# 팀 업무 한 사이클 사용 안내

## 1. 주제를 프로젝트로 준비

관리자가 프로젝트 이름·목표·성공 기준·기간을 작성한다. 팀원은 작업 화면의 프로젝트 선택이나 **내 업무**에서 담당 카드를 연다. 별도의 주제 계층을 만들 필요 없이 프로젝트와 상·하위 작업으로 업무를 나눈다.

## 2. 카드에 결과와 책임을 정하기

카드마다 기대 산출물, 확인 가능한 완료 기준, 담당자와 기한을 적는다. 사람별로 담당 업무가 다르면 하위 카드를 사용한다. 담당자·검토자는 현재 업무 작성 권한이 있는 회원/관리자 중에서 정한다. 기존 게스트 배정은 그대로 보이지만 수행 불가 안내가 나온다.

검토 방식은 시작 전에 선택한다.

- **담당자 완료:** 담당자의 제출물을 등록하고 담당자 또는 관리자가 완료 근거를 남긴다.
- **검토자 승인 후 완료:** 담당자와 다른 검토자를 지정하고 아래 버전 검토 절차를 거친다. 작업을 시작한 뒤 검토 방식을 해제할 수 없다.

간트의 완료율은 실제 완료한 말단 카드 수이다. 기간이 지났다고 자동 완료되거나 상위 카드가 선행 조건이 되지는 않는다.

## 3. 작업과 산출물 제출

담당자는 진행·차단 상태를 갱신한다. 차단 또는 완료한 업무를 다시 열 때에는 사유를 작성한다. 일반 업무 상태 사유는 작업을 볼 수 있는 사용자에게 보인다.

제출물에는 본문, HTTP(S) 자료 링크, 파일을 함께 넣을 수 있다. 한 번의 파일 선택은 최대20개·합계20MiB이다. 수정에는 변경 요약이 필요하고 v2/v3처럼 새 버전이 생긴다. 이전 본문·링크·파일은 **버전·검토 이력**에서 확인한다. 현재 버전에서 파일을 제외해도 이전 버전 파일은 남는다.

기존 자료는 이 기능 도입 시 남아 있던 내용을 첫 snapshot으로 표시한다. 이미 오래전에 덮어쓴 내용을 복원한 것은 아니며 기존 댓글은 버전 미지정으로 표시한다.

## 4. 검토와 보완

현재 담당자의 제출물에서 **이 버전 검토 요청**을 선택한다. 지정 검토자는 **내 업무 → 내 검토 대기**에서 정확한 버전을 열고 승인하거나 사유를 적어 보완 요청한다.

보완 요청 뒤에는 기존 버전을 그대로 다시 요청할 수 없다. 작성자가 새 버전을 만든 뒤 재요청한다. 승인하면 그 버전을 근거로 카드가 완료된다. 새 버전 작성·업무 내용 변경·다시 열기는 현재 승인을 해제하고 이전 판정을 이력에 남긴다. 이전 승인이 새 버전에 자동 적용되지는 않는다.

작성자·담당자·그 버전의 편집자는 관리자여도 자체 승인할 수 없다. 지정 검토자의 권한이 변경되면 담당자/관리자가 검토를 취소하고 적절한 검토자로 다시 지정할 수 있다.

## 5. 공개 범위와 돌아오기

- 공개 제출물은 로그인 사용자에게 보인다.
- 비공개 제출물은 원래 작성자와 관리자/슈퍼관리자만 본다. 담당자·검토자로 지정하는 것만으로 열람권이 늘지 않는다.
- 이전 버전은 현재 제출물과 당시 버전의 공개 범위를 함께 적용한다. 현재 공개로 바꿔도 이전 비공개 원문/댓글이 자동 공개되지는 않는다.
- 자세한 검토 의견은 해당 제출물의 이력에 남고 일반 작업 목록에는 노출하지 않는다.

**내 업무**에서 담당/기여/검토 대기·상태·기한 초과를 선택한다. 카드 또는 버전을 열어 작업한 뒤 **내 업무로 돌아가기**를 누르면 필터와 선택 위치가 유지된다. 완료되어 목록에서 빠지면 안내에 따라 상태 필터를 바꿔 확인한다.

이력은 자동 만료되지 않는다. 프로젝트·작업·제출물 전체 삭제는 이전 버전과 파일도 포함하는 별도 명시 확인 절차다.


## 6. 반복 주제는 템플릿에서 준비

작업 화면에서 조사 또는 산출물 예시 템플릿을 선택한다. 미리보기에서 제목·설명·산출물·완료 기준·담당자·날짜를 수정하고 필요 없는 카드는 제외한다. 상위 카드를 제외하면 하위도 빠진다. 기본 담당자는 미배정이며 생성 전에 팀의 실제 업무에 맞게 검토한다. 저장 중에는 입력/취소를 잠시 막고, 오류가 나면 미리보기를 유지한다. 동일 요청을 다시 보내도 중복 카드가 생기지 않는다.

## 7. 선행 업무와 현황 숫자 보기

WBS의 상위/하위 관계와 실제 선행 조건은 다르다. 계획/차단 상태의 카드에서 같은 프로젝트의 선행 업무를 선택한다. 순환은 허용하지 않는다. 선행이 완료되지 않으면 시작·완료·검토 요청/판정을 보류하며 사유를 표시한다. 검토 취소와 사유 있는 재오픈은 가능하다. 선행을 다시 열어도 후행의 예전 완료/승인 이력은 지우지 않고 현재 차단을 경고한다.

작업 화면의 미배정·지연·선행 차단·검토 대기 숫자에서 해당 카드 목록을 연다. 이 현황 숫자는 상위 카드를 포함하며 간트의 말단 카드 완료율과 구분해 표시한다. 날짜를 바꿔도 후행 일정을 자동으로 밀지는 않는다.

## 8. 업무와 제출 버전 검색

상단 또는 모바일 메뉴의 **검색**을 연다. 업무 제목/설명, 제출 본문/작성자/파일명을 검색하고 프로젝트·담당·상태·기한으로 좁힌다. 파일 내부 내용이나 외부 URL을 자동으로 가져오지는 않는다.

기본은 최신 버전이다. **현재 승인된 버전**은 아직 취소/변경되지 않은 현재 선택 승인본이고, **이전 버전 포함**은 본인이 볼 수 있는 과거 snapshot도 포함한다. 업무 카드에는 버전 필터를 적용하지 않는다. 결과에서 일치한 파일명과 버전을 확인하고 정확한 카드/버전을 연다.

## 9. 내 알림에서 다음 행동 찾기

**알림**에는 자신에게 배정된 업무, 현재 검토 요청, 보완/승인 결과와 자신의 제출물에 달린 댓글을 표시한다. 전체 변경을 모든 사용자에게 보내지 않는다. **읽음 표시**는 업무·검토 이력을 지우지 않으며 전체 알림에서 다시 볼 수 있다.

재배정/검토 취소/권한 변경으로 더 이상 유효하지 않은 알림은 숨긴다. 원래 작성자의 제출물 소유 조회권은 유지되므로 담당자가 달라져도 자신의 제출물 댓글은 확인할 수 있다. 외부 이메일/메신저 발송이나 알림을 읽은 뒤 자동 업무 실행은 없다.
