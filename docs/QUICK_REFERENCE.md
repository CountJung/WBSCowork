# WBSCowork 빠른 참조 (Quick Reference Card)

## 핵심 개념
**WBSCowork = 태스크 기반 산출물 협업 시스템**
- WBS/간트 기반 업무 관리
- 태스크 단위 산출물 제출
- 팀원 간 피드백 & 협업

---

## 역할 및 권한 요약

| 역할 | 접근 범위 | 주요 기능 |
|------|---------|---------|
| **슈퍼관리자** | 모든 기능 | DB, 로그, 설정, 사용자 관리 |
| **관리자** | /admin, /admin/users | 사용자 관리, 모든 제출물 조회 |
| **일반사용자** | 홈, 태스크, 산출물 | CRUD, 공개/본인 비공개 조회 |
| **게스트** | 공개 제출물만 | 읽기 전용 |

---

## 산출물 공개 범위

### 🌐 공개 (public)
모든 인증 사용자가 조회 가능

### 🔒 비공개 (private)
- 작성자 (본인)
- 관리자 역할 사용자
- 슈퍼관리자

## 주요 화면 및 경로

| 화면 | URL | 대상 사용자 |
|------|-----|-----------|
| 홈 | `/` | 전체 |
| 태스크 | `/tasks` | 전체 |

## 사용 흐름 (4단계)

```
1️⃣ 프로젝트 선택 (홈)
        ↓
2️⃣ 태스크 확인 (Gantt/리스트)
        ↓
3️⃣ 산출물 제출 (태스크 상세)
        ↓
4️⃣ 협업 & 피드백 (댓글)
```

---

## 태스크 CRUD

**생성 (CREATE)**
- 홈 → "새 태스크" → 정보 입력 → 저장

**조회 (READ)**
- 홈 Gantt 차트 또는 리스트 클릭

**수정 (UPDATE)**
- 태스크 상세 → "편집" → 변경 → 저장

**삭제 (DELETE)**
- 관리자 권한 필요 (태스크 상세 → "삭제")

## 파일 첨부 규칙

✅ **지원 파일**: 모든 일반 파일 형식
- 문서: PDF, Word, Excel
- 이미지: JPG, PNG, GIF
- 기타: ZIP, 비디오 등

⚠️ **제한사항**
- 최대 파일 크기: 시스템 설정 확인
- 대용량 파일: 압축 후 업로드

---

## 댓글 에티켓

✅ **좋은 댓글**
- "좋은 작업! 이 부분을 확인해주세요: ..."
- "상세한 설명 감사합니다. 다음 스텝은..."

❌ **피해야 할 댓글**
- 비판적, 모욕적 표현
- 명확하지 않은 피드백
- 타이핑 오류

---

## 관리자 필수 확인 사항

**초기 설정 (처음 1회)**
1. `/admin/database` → DB 생성
2. `/admin/settings` → 환경변수 확인
3. `/admin/users` → 사용자 역할 설정

**정기 점검**
- `/admin/logs` → 에러 확인
- 사용자 권한 정기 검토

## 문제 해결

| 문제 | 해결법 |
|------|-------|
| 로그인 안됨 | 브라우저 캐시 삭제 후 재시도 |
| 파일 업로드 실패 | 파일 크기/형식 확인 |
| 화면 렌더링 이상 | 다른 브라우저 시도 |
| Gantt 안 보임 | 프로젝트가 선택되었는지 확인 |
| 권한 없음 오류 | 관리자에게 권한 승격 요청 |

## 환경변수 주요 설정

```
# Google OAuth
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...

# 인증
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=...

# MariaDB
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_NAME=wbscowork

# 파일 업로드
UPLOAD_MAX_FILE_SIZE_MB=50
UPLOAD_DIR=/uploads

# 슈퍼관리자 (한 이메일만)
SUPERUSER_EMAIL=admin@example.com

# 로깅
LOG_DIR=/logs
LOG_RETENTION_DAYS=30
```
